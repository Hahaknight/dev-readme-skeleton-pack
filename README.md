# Dev README Skeleton Pack

**6 copy-paste README skeletons for real projects — stop staring at a blank README.**

🔗 **Grab them online: <https://hahaknight.github.io/dev-readme-skeleton-pack/>**

## Why this exists

Every README guide tells you *what sections to include* — nobody hands you the sections pre-written. This pack gives you fill-in-the-blank skeletons matched to your project type, because a library README and an experiment README are different documents:

1. **Library / Package** — install, minimal example, API surface, versioning
2. **CLI Tool** — the one-liner demo, flags table, exit codes, shell completion
3. **API / Service** — auth, endpoint reference, rate limits, error format
4. **App (mobile/desktop)** — store links, screenshots, build-from-source
5. **Template / Boilerplate** — what you get, how to start, how to customize
6. **Experiment / Research repo** — the question, method, how to reproduce, findings

Each skeleton includes the section *and* a hint of what good content in it looks like — so you're editing, not composing from zero.

## Self-host

Single static `index.html`, zero dependencies.

```bash
git clone https://github.com/Hahaknight/dev-readme-skeleton-pack
# open index.html directly, or enable GitHub Pages on your fork
```
